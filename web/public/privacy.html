개인정보처리방침

시행일: 2026년 8월 27일

비투디(이하 "회사")는 공간정보 데이터 API 서비스 b2d_geo를 제공하면서 개인정보를 최소한으로 수집하고, 수집한 정보를 이 방침에 적은 대로만 처리합니다. 서비스는 회원 가입 절차가 없으며, 무료 데모 키는 개인정보 입력 없이 발급됩니다.

1. 수집하는 개인정보의 항목과 방법

구분항목수집 방법
문의·구독 신청 이메일 주소, 이용자가 메일 본문에 기재한 정보(이름 또는 회사명 등) 이용자가 회사에 보낸 이메일 수신
API 키 발급·관리 키의 해시값과 앞자리 일부(원문 미저장), 신청 시 기재한 소유자명, 발급·회수 시각 유료 키 발급 시 서버에 기록
서비스 이용 기록 API 키 식별자, 호출한 엔드포인트, 집계 시각, 호출 건수 (IP 주소 미포함) API 호출 시 자동 집계
웹서버 접근 로그 IP 주소, 요청 경로, 요청 시각, 브라우저 정보(User-Agent) 웹서버가 자동 기록 (보안·장애 대응 목적)
  • 무료 데모 키 발급 시에는 어떤 개인정보도 입력받지 않습니다.
  • 서비스는 쿠키를 사용하지 않습니다. 화면 테마 설정은 이용자 브라우저의 로컬 저장소에만 저장되며 서버로 전송되지 않습니다.
  • 행태 분석, 광고, 추적 도구를 사용하지 않습니다.

2. 개인정보의 처리 목적

  • 문의 응대, 구독 신청 처리, API 키 발급과 회수
  • 요금 산정과 월 한도 관리(이용 기록 집계)
  • 서비스 보안, 부정 이용 방지, 장애 원인 분석(접근 로그)

3. 결제 정보의 처리

결제는 전자결제대행사(PG)를 통해 처리되며, 회사는 이용자의 카드번호 등 결제수단 정보를 수집하거나 저장하지 않습니다. 결제수단 정보는 PG사가 자체 약관과 개인정보처리방침에 따라 처리합니다. 회사는 결제 승인 여부와 결제 식별 정보만 전달받습니다.

4. 보유 기간과 파기

항목보유 기간근거
웹서버 접근 로그(IP 포함)90일 후 자동 파기(로그 순환)보안·장애 대응에 필요한 최소 기간
계약·결제 관련 기록5년전자상거래법 제6조
소비자 불만·분쟁 처리 기록3년전자상거래법 제6조
API 키 정보·이용 기록구독 종료 후 위 법정 보존 기간까지요금 정산·분쟁 대응
문의 이메일처리 완료 후 3년재문의 대응

보유 기간이 지난 개인정보는 지체 없이 파기합니다. 전자 파일은 복구할 수 없는 방법으로 삭제합니다.

5. 제3자 제공

회사는 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 따라 수사기관 등이 적법한 절차로 요청하는 경우는 예외로 합니다.

이용자는 언제든지 자신의 개인정보에 대한 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 요청은 아래 보호책임자 이메일로 하면 되고, 회사는 지체 없이 처리 결과를 알립니다. 법정 보존 의무가 있는 기록은 보존 기간 중 삭제가 제한될 수 있으며, 이 경우 사유를 안내합니다.

8. 안전성 확보 조치

  • 접근 로그는 90일 순환 정책으로 자동 파기됩니다.
  • 수집 항목 자체를 최소화하여 유출 시 피해 범위를 줄입니다.
