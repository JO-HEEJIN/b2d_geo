환불정책

시행일: 2026년 8월 27일

이 정책은 비투디(이하 "회사")가 제공하는 b2d_geo 관리형 API 구독(월 정액 선불)에 적용됩니다. 온프레미스 라이선스와 벌크 배치는 개별 계약의 환불 조항을 따릅니다.

1. 청약철회 (전액 환불)

  • 결제일로부터 7일 이내이고 해당 결제 기간에 API 호출 실사용이 없는 경우, 전자상거래 등에서의 소비자보호에 관한 법률에 따라 전액 환불합니다.
  • "실사용 없음"은 발급된 유료 API 키의 호출 기록이 없는 상태를 말하며, 회사의 사용량 집계 기록을 기준으로 확인합니다.

2. 사용 개시 후의 해지

  • API 호출을 시작한 이후에는 해당 월 요금의 일할 환불을 제공하지 않습니다.
  • 해지를 요청하면 다음 결제가 중단되며, 이미 결제한 기간이 끝날 때까지 서비스를 계속 이용할 수 있습니다.
  • 월 한도(100,000건) 도달로 호출이 제한되는 것은 정상적인 계약 이행이며 환불 사유가 아닙니다.

3. 서비스 장애 보상

연속 24시간 이상 서비스 이용이 불가능한 장애가 발생한 경우, 해당 기간만큼 이용 기간을 연장하거나 월 요금을 일할 계산하여 크레딧으로 보상합니다. 천재지변, 클라우드 인프라 사업자의 장애 등 당사가 통제할 수 없는 사유는 제외합니다.

4. 회사 사유의 환불

  • 회사가 서비스를 종료하는 경우 남은 구독 기간의 요금을 일할 계산하여 환불합니다.
  • 중복 결제, 결제 오류 등 회사 또는 결제 시스템의 잘못으로 잘못 청구된 금액은 확인 즉시 전액 환불합니다.

5. 환불 절차

  • 환불 요청은 이메일(info@birth2death.com)로 받습니다. 결제 확인에 필요한 정보(결제일, 결제 수단, API 키 앞자리)를 함께 보내 주세요.
  • 회사는 영업일 기준 3일 이내에 처리 결과를 회신합니다.
  • 환불금 지급은 전자결제대행사(PG)의 취소 절차에 따라 진행되며, 결제 수단에 따라 3~7영업일이 걸릴 수 있습니다.

6. 기타

이 정책에서 정하지 않은 사항은 이용약관과 전자상거래 관련 법령을 따릅니다. 이 정책과 법령이 다른 경우 이용자에게 유리한 쪽을 적용합니다.
