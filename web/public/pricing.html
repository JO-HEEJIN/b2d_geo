온프레미스 라이선스

주소 데이터가 고객 인프라 밖으로 나가지 않습니다. 엔진과 데이터베이스 전체를 고객 인프라에 배포하고, 내부 호출은 건수 제한 없이 사용합니다. 외부 API 호출 이력이 남으면 안 되는 조직을 위한 형태입니다.
