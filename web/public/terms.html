B b2d_geo
지도 데모 배치 API 문서 요금

이용약관

시행일: 2026년 8월 27일

제1조 (목적)

이 약관은 비투디(이하 "회사")가 제공하는 공간정보 데이터 API 서비스 b2d_geo(이하 "서비스")의 이용 조건과 절차, 회사와 이용자의 권리·의무·책임 사항을 정하는 것을 목적으로 합니다.

제2조 (정의)

  • "서비스"란 회사가 API 형태로 제공하는 공간정보 데이터 조회 기능(지오코딩, 역지오코딩, 필지 조회, 공시지가, 용도지역, 토지특성, 부동산 실거래가, 장소 검색 등)과 이에 부속된 웹 데모, 배치 변환 도구, MCP 연동 기능을 말합니다.
  • "이용자"란 이 약관에 따라 서비스를 이용하는 개인 또는 법인을 말합니다.
  • "API 키"란 서비스 호출 권한을 식별하기 위해 회사가 발급하는 인증 수단을 말합니다.
  • "데모 키"란 서비스 체험을 위해 무료로 발급되는 제한된 권한의 API 키를 말합니다.
  • "구독"이란 이용자가 월 단위 요금을 선불로 지불하고 정해진 한도 내에서 서비스를 이용하는 계약을 말합니다.

제3조 (약관의 게시와 개정)

  • 회사는 이 약관을 서비스 웹사이트에 상시 게시합니다.
  • 회사는 관련 법령을 위반하지 않는 범위에서 약관을 개정할 수 있으며, 개정 시 시행일과 개정 사유를 명시하여 시행일 7일 전(이용자에게 불리한 변경은 30일 전)부터 웹사이트에 공지합니다.
  • 이용자가 개정 약관 시행일 이후에도 서비스를 계속 이용하는 경우 개정 약관에 동의한 것으로 봅니다.

제4조 (서비스의 내용)

  • 서비스는 국가 공공데이터(국토교통부, 행정안전부, 한국부동산원, 국가공간정보포털 등)를 기반으로 하며, 원자료에 적재된 사실을 그대로 반환합니다. 회사는 데이터에 대한 보정, 추정, 예측, 추천을 하지 않습니다.
  • 개별공시지가와 토지특성 등 일부 데이터는 지역 선택 적재 방식으로 제공됩니다. 미적재 지역은 오류가 아닌 별도의 응답 코드(REGION_NOT_LOADED)로 구분하여 응답합니다.
  • 데이터는 원천 기관의 공표·갱신 주기에 따라 갱신되며, 원천 데이터와 시차가 있을 수 있습니다.

제5조 (이용계약의 성립)

  • 데모 키는 웹사이트에서 즉시 발급되며, 발급 시점에 무료 이용계약이 성립합니다.
  • 유료 구독은 이용자가 이메일로 신청하고 회사가 결제 확인 후 API 키를 발급한 시점에 성립합니다. 결제 시스템 도입 후에는 결제 완료 시점에 성립합니다.
  • 회사는 서비스 제공이 곤란한 기술적 사유가 있거나 신청 정보가 허위인 경우 신청을 거절할 수 있습니다.

제6조 (API 키의 관리)

  • API 키의 보관과 비밀 유지 책임은 이용자에게 있으며, 키를 사용한 모든 호출은 이용자의 이용으로 봅니다.
  • 키가 제3자에게 노출된 경우 이용자는 지체 없이 회사에 알려야 하며, 회사는 기존 키를 회수하고 새 키를 발급합니다.
  • 회사는 키 원문을 저장하지 않고 해시만 보관하므로, 키 분실 시 재발급으로만 대응할 수 있습니다.

제7조 (요금과 결제)

  • Standard 구독 요금은 월 9,900원(부가가치세 포함)이며, 월 100,000건의 호출 한도와 초당 5건의 속도 제한이 적용됩니다. 요금과 한도는 요금 페이지에 게시합니다.
  • 구독은 선불 방식입니다. 사용량 집계는 UTC(협정 세계시) 월 기준입니다.
  • 월 한도를 초과한 호출은 처리되지 않고 안내 응답(HTTP 429)이 반환됩니다. 한도 초과에 따른 자동 추가 과금은 없습니다.
  • 환불은 별도의 환불정책에 따릅니다.

제8조 (이용 제한)

  • 이용자는 다음 행위를 해서는 안 됩니다: 서비스의 안정성을 해치는 비정상적 대량 호출, 속도 제한이나 인증 체계의 우회 시도, 타인의 API 키 무단 사용, 법령에 위반되는 목적의 이용.
  • 회사는 위 행위가 확인된 경우 사전 통지 후 서비스 이용을 제한하거나 계약을 해지할 수 있습니다. 긴급한 경우 선조치 후 통지할 수 있습니다.
  • 공공데이터의 이용 조건은 공공누리 등 원천 기관의 이용 약정을 따릅니다.

제9조 (데이터의 성격과 책임의 한계)

  • 서비스가 제공하는 데이터는 참고용입니다. 공시지가, 토지 정보 등에 대해 법적 효력이 있는 증명이 필요한 경우 정부가 발급하는 공식 문서(부동산공시가격알리미, 토지이음, 등기사항증명서 등)를 기준으로 해야 합니다.
  • 회사는 원천 공공데이터 자체의 오류, 누락, 갱신 지연에 대해 책임지지 않습니다. 다만 원자료와 서비스 응답이 불일치하는 오류는 통지받은 후 신속히 수정합니다.
  • 회사의 손해배상 책임은 회사의 고의 또는 중대한 과실이 없는 한 이용자가 손해 발생 직전 1개월간 회사에 지불한 요금을 한도로 합니다.

제10조 (서비스의 변경과 중단)

  • 회사는 서비스의 내용, API 사양, 제공 데이터 범위를 변경할 수 있으며, 이용자에게 영향이 있는 변경은 사전에 공지합니다.
  • 정기 점검, 설비 교체, 원천 데이터 갱신 등을 위해 서비스가 일시 중단될 수 있으며, 계획된 중단은 사전에 공지합니다.
  • 서비스를 종료하는 경우 30일 전에 공지하고, 남은 구독 기간에 대한 요금을 일할 계산하여 환불합니다.

제11조 (계약 해지)

  • 이용자는 언제든지 이메일로 구독 해지를 요청할 수 있습니다. 해지 시 다음 결제가 중단되며, 이미 결제한 기간이 끝날 때까지 서비스를 이용할 수 있습니다.
  • 환불 조건은 환불정책에 따릅니다.

제12조 (준거법과 관할)

이 약관은 대한민국 법률에 따라 해석되며, 서비스 이용과 관련한 분쟁은 민사소송법에 따른 관할 법원에 제기합니다.
