# DRAFT. 발송 금지. 발송용 확정은 별도로 한다.

대상: 물류, 커머스 (대량 주소 정제)
단가 출처: developers.kakao.com/docs/ko/getting-started/quota (2026-08-16 확인,
"주소로 좌표 변환" 0.5원/건, 무료 쿼터 월 300만 건, 카카오맵 무료 쿼터는
개발자 계정 첫 활성화 앱에만). 발송 직전 재확인할 것.
훅 숫자는 상대 회사의 실제 처리량으로 바꿔서 보낼 것.

---

월 3,000만 건 주소를 좌표로 바꾸면 카카오 "주소로 좌표 변환" API 기준 월 1,350만 원입니다. 무료 구간 300만 건을 빼고 건당 0.5원으로 계산한 숫자이고, 연으로는 1억 6천만 원이 넘습니다.

무료 시대는 끝났습니다. 카카오는 2026년 7월부터 무료 쿼터를 개발자 계정의 첫 활성화 앱에만 줍니다. 네이버는 기존 무료 지도 API의 신규 신청을 차단하고 전량 유료화했습니다. 대량 처리 조직일수록 이 변화가 바로 비용이 됩니다.

b2d_geo는 공공데이터 기반 자체 엔진이라 콜당 원가가 사실상 없습니다. 그래서 세 가지 방식을 제안합니다. 주소 리스트를 넘기면 좌표와 필지 필드를 일괄 반환하는 벌크 배치, 정액 API 구독, 그리고 내부 호출 무제한 온프레미스. 온프레미스는 주소 데이터가 고객 인프라 밖으로 나가지 않습니다.

정확도는 검증돼 있습니다. 전국 800개 주소 질의 100% 정답, 카카오와 동일 주소 100건 수동 대조 일치, 응답 0.03초에서 0.1초. 지번과 도로명이 섞인 주소도 처리합니다.

지금 처리하시는 월 주소량을 알려주시면 카카오 단가 대비 견적을 바로 드리겠습니다. 라이브 API를 15분 안에 직접 보여드리겠습니다.
