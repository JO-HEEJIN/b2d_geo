## 1. 표준지공시지가

| 항목 | 내용 |
|---|---|
| 제공처 | 국토교통부 (data.go.kr) |
| 기준/갱신 | 매년 1월 1일 기준 산정, 연 1회 공시 |
| 포맷 | SHP + CSV 제공 |
| 좌표계 | 확정 필요 (SHP .prj 파일로 확인 후 ST_Transform) |
| 규모 | 전국 수십만 필지 (실파일 카운트로 확정) |
| 키 필드 | PNU(19자리), 기준연도 |
| 포함 속성 | 공시지가(원/제곱미터), 지목, 용도지역, 이용상황, 도로접면, 지형고저, 지형형상, 면적 |
| 적재 대상 | standard_lots |
| 캐비앳 | 토지특성 컬럼이 포함되므로 데이터셋 3(토지특성정보)과 중복 필드 발생. 표준지 범위에서는 본 데이터셋을 우선하고, 비표준지 필지의 특성은 데이터셋 3으로 보완한다. 두 소스 간 코드값 체계 일치 여부를 ETL에서 검증 |
| 검증 앵커 | 부동산공시가격알리미 (realtyprice.kr) |

## 4. 토지이용계획 (용도지역·지구 폴리곤)

| 항목 | 내용 |
|---|---|
| 제공처 | 국가공간정보포털 (UPIS 계열) |
| 포맷 | SHP (WMS/WFS API도 존재하나 사용 금지 — 벌크 원칙, NFR-08) |
| 좌표계 | 확정 필요 (.prj) |
| 적재 대상 | use_zones |
| 캐비앳 | 폴리곤 유효성(self-intersection) 검사 필수: ST_IsValid 실패 지오메트리는 ST_MakeValid 후 적재하고 건수를 learning_log에 기록. 용도지역과 지구·구역은 레이어가 분리되어 있을 수 있으므로 레이어 목록을 실파일에서 확정 |
| 검증 앵커 | 토지이음 필지별 토지이용계획 확인원 |

## 5. 토지 매매 실거래가

| 항목 | 내용 |
|---|---|
| 제공처 | 국토교통부 실거래가 공개시스템 (rt.molit.go.kr) CSV 벌크 / 공공데이터포털 오픈API (법정동 5자리 + 계약년월 단위) |

| 검증 앵커 | rt.molit.go.kr 검색 화면 |

## 7. 공통 사항

- 라이선스: 전 데이터셋의 공공누리 유형과 이용조건을 ETL 착수 시 개별 확인하고
  출처표시 요건을 API 문서 하단과 고객 계약서에 반영한다 (BRD 6절).
- provenance: 모든 행에 source, source_version 필수 (NFR-10, TC-S05 확장 대상).
- 위치 정밀도 등급 체계 (전 모듈 공통 어휘):
  PARCEL(필지 정밀) > JIBUN_PARTIAL(부분 지번) > EMD_CENTROID(법정동 중심점).
- 갱신 캘린더: 연 1회(1~4) 매년 상반기 일괄, 월 배치(5~6) 매월 말 실행.
  운영 절차는 06 문서 흐름 E에 증보됨.
