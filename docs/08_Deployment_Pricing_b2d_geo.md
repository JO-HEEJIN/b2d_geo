## 0. 시장 상황 — 왜 지금이 기회인가 (2025~2026 경쟁 지형 변화)

범용 지오코딩은 "카카오/네이버가 무료라 못 이긴다"가 오랜 전제였다. **그 전제가 2025~2026에 무너졌다.**

| 공급자 | 현재 상태 (확인 2026-07) | 단가 |
|---|---|---|
| **네이버** Geocoding | **2025-05-22 신규 이용 신청 차단** + **2025-07-01 무료 종료** → 신규 사업자는 발급 자체 불가 | 유료(무료쿼터 0) |
| **카카오** 로컬(주소검색) | 2026-07-21 무료 쿼터 축소(개발자 계정 첫 앱만), 비즈월렛 연결·사용량 과금 | **정상 건당 50원** / 할인 건당 10원(2026-02-02~12-31 한시) |
| **구글** Maps Platform | 2025-05 대폭 인상 | 고가(지오코딩 ~$5/1,000) |
| **b2d_geo** (자체 호스팅) | 공식 공공데이터 기반, 자체 소유 | **콜당 한계비용 ~0원** (서버비만) |

**핵심 함의 셋:**
1. **네이버는 신규 사업자에게 닫혔다** — 지금 창업/신규 도입하는 조직은 네이버 지오코딩을 받을 수 없다. 남은 선택지가 좁아졌고, 그 틈에 b2d_geo가 대안이 된다.
2. **카카오는 유료다** — 정상 50원/건. 대량 처리에서 비용이 폭증한다(§2-4 비교표).
3. **따라서 경쟁축이 셋이 됐다**: (a) **소유** — 제3자 API 의존 제거, 온프레미스, (b) **깊이** — 필지→공시지가→용도지역→감정평가(범용 API가 안 가는 곳), (c) **이제 비용** — 카카오 유료화·네이버 폐쇄로 범용 지오코딩 비용에서도 현실적 우위.

## 1. 배포 형태 (3가지)

스택: **Go 서버(`cmd/b2d-server`) + PostGIS(공식 데이터 적재)**. 배포는 이 두 컴포넌트 + 데이터 프로비저닝의 조합이다.

### 1-1. 관리형 API (우리가 호스팅) — SaaS
- 우리가 서버+DB 운영, 고객은 API 키로 호출.
- 대상: 자체 인프라 없는 스타트업/앱, 소~중량.
- 과금: 사용량 기반(§2-1 벌크 요금과 연계) 또는 월 정액 쿼터.

### 1-2. 온프레미스 (고객 자체 호스팅) — 라이선스
- 고객 인프라에 Docker 이미지 + PostGIS(데이터 스냅샷) 배포. **주소가 외부로 안 나감.**
- 대상: **정부·금융·부동산·감정평가사** — 데이터 residency 규제로 제3자 API 사용이 법적으로 불가한 조직. **이 축은 카카오/네이버가 구조적으로 못 한다.**
- 라이선스 게이트 준수: 원천 데이터 재배포 조건(AI Hub 약관, RDD CC BY 등)을 온프레미스 라이선스 계약에 반영. dacl10k 같은 NC 데이터는 코어에서 이미 배제됨.
- 과금: 연 라이선스 + 데이터 갱신 구독(선택).

### 1-3. 벌크 배치
- 고객이 주소 리스트를 넘기면 좌표/필지/부동산 필드를 일괄 반환(파일 또는 배치 API).
- 대상: 1회성 대량 정제(수백만 건), 데이터 마이그레이션, 분석용.
- 과금: 건당 종량(카카오 대비 대폭 언더컷) 또는 볼륨 정액.

### 1-4. 배포 아티팩트 (확정 필요)
- Go 서버 Docker 이미지(멀티스테이지, 정적 바이너리).
- PostGIS + 적재된 데이터: **온프레미스는 데이터 스냅샷 전달**(초기 적재 시간 절약) 또는 ETL 스크립트+원천 프로비저닝 중 택. (스냅샷 배포 시 라이선스 재배포 조건 확인 필수.)
- config/env: DB 접속, 라이선스 키, rate limit, 데이터 버전.
- **데이터 신선도**: 공공데이터 갱신 주기(주소 월, 공시지가 연 등) → 갱신 파이프라인이 신뢰의 생명줄(§0-(b) 깊이 축의 전제).

## 2. 요금제 설계 (3축)

> 단가 **확정 (2026-07-27, 사업 결정)**. 근거: §0 경쟁분석 + §2-5 정확도. 원가~0(공공데이터), 무료티어 볼륨경쟁은 비목표.

### 2-1. 벌크 / 종량 (범용 지오코딩) — "카카오보다 싸다"
- **포지션**: 카카오 정상 50원/건(할인 10원) 대비 명확히 언더컷. 네이버는 신규 발급 불가라 애초에 대안이 없다.
- **구조(확정)**: 볼륨 티어 **30 / 20 / 10원** (~10만 / ~100만 / 100만+ 건) + **월 최소 30만원**, 일일 제한 없음. 100만 건 = 1,000만원(카카오 정상 5,000만원의 1/5).
- **핵심 메시지**: "고정 요금표 + 자체 소유라 카카오 인상/정책변경 리스크에서 자유롭다."

### 2-2. 온프레미스 라이선스 — "카카오/네이버가 못 파는 축"
- **포지션**: 데이터 residency가 필요한 조직에게 **유일한 현실적 선택지**. 무제한 내부 호출 + 외부 유출 0.
- **구조(확정)**: **연 라이선스 3,000만원** + **데이터 갱신구독 800만원/년**(분기 스냅샷). 무제한 내부 호출. 대규모 기관·부동산 풀셋은 협의 가산.
- **핵심 메시지**: "콜당 과금 없음. 100만 건이든 1억 건이든 내부에서 무제한."

### 2-3. 부동산 필드 (감정평가급) — "아무도 안 파는 깊이" (최고 마진)
- **포지션**: 주소→필지(PNU)→공시지가→용도지역→실거래→감정평가. 범용 지오코더엔 없는 데이터 그래프.
- **구조(확정)**: 월 구독 **Starter 30만 / Pro 100만 / Enterprise 협의**. Starter=parcel+공시지가, Pro=실거래+용도지역+상향 한도, Ent=감정평가 모듈+무제한+SLA. 감정평가법인/프롭테크/금융 타겟.
- **핵심 메시지**: "지오코딩이 아니라 토지 인텔리전스. 이건 카카오/네이버/구글 어디에도 없다."

### 2-4. 경쟁 비용 비교표 (판매 근거 — 대량 시나리오)

**주소 100만 건 지오코딩 1회:**
| 공급자 | 계산 | 비용 |
|---|---|---|
| 카카오 (정상 50원/건) | 50 × 1,000,000 | **약 5,000만원** |
| 카카오 (할인 10원/건, 한시) | 10 × 1,000,000 | 약 1,000만원 |
| 네이버 | — | **발급 불가(신규 차단)** |
| **b2d_geo 온프레미스/벌크** | 서버비 + 라이선스 | **한계비용 ~0 (콜당 과금 없음)** |

> 이 표가 6-3의 핵심 판매 무기. 아래 6-2 정확도 검증으로 "싸고 + 충분히 정확"이 함께 선다.

### 2-5. 정확도 검증 (6-2, 실측 2026-07-27)

측정: `buildings`에서 무작위 실주소 100건(재현샘플 seed 0.42) → b2d `/v1/geocode`와
카카오 로컬(주소검색)에 **동일 문자열** 질의 → 공식 juso 좌표 기준 거리 측정.
하니스 `scripts/kakao_compare.sh`, 증거 `scripts/out/general_100.csv`.

| 지표 | b2d | 카카오 |
|---|---|---|
| 매치율 | 100/100 | 100/100 |
| ↔공식좌표 거리 중앙값 | **0.0m** | 6.2m |
| 평균 / p90 / max | 0 / 0 / 0 | 10.6 / 16.1 / **111.2m** |

카카오 누적: ≤5m 37% · ≤10m **79%** · ≤25m 92%.

**정직한 해석**: b2d는 공식 juso 입구좌표를 그대로 반환(0m). 카카오는 자체 지오코딩
기준점(건물/필지 중심 등)이라 중앙값 6.2m 차이 — "카카오 오류"가 아니라 **기준점 차이**.
단 상위 이상치(지하·시골 대필지)는 수십 m까지 벌어지고, 최악 12~60m 케이스는 이웃 건물에
더 가까워 오도 가능(이상치 수동검증 = 필지+건물 레이어 대조로 확인). 필지·감정평가처럼
공식좌표가 법적 기준인 용도에선 b2d가 정의상 정확.

**신설 구 서브검증** (40건, 화성 만세·효행·병점·동탄구 — 2026-02-01 신설 실제 구):
카카오도 40/40 해석 + 새 구명 정확 에코, 중앙값 7.2m → **행정개편 신선도는 이 건에서
b2d 차별점 아님**(카카오 반영 완료). 증거 `scripts/out/newgu_40.csv`.

**판매 프레이밍 결론**: "카카오보다 정확"이 아니라 — ① **커버리지 동등**(양쪽 100%)
② **공식좌표 정합**(b2d 0m, 법적 기준) ③ **꼬리 안정성**(카카오 이상치 수십 m)
④ **0원**(카카오 정상 50원/건). 정확도는 "충분히 대등 + 공식 기준 정합", 우위 핵심은
**소유·비용**이다.
