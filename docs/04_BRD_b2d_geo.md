## 1. 사업 배경 및 문제 정의

### 1.1 시장 문제
1. 국내 위치 API는 카카오/네이버 과점 구조이며, 대량 사용 시 일일 호출 제한과
   약관상 제약(결과 저장/재가공 제한 등)이 병목이 된다.
2. 금융/공공/의료 등 규제 산업은 외부 API 호출 자체가 불가한 망분리 환경이 많아
   기존 SaaS형 위치 API를 아예 사용할 수 없다.
3. 부동산 실무(감정평가, 토지용역, 프롭테크)는 좌표뿐 아니라 PNU/지적/필지 폴리곤이
   필요하지만, 범용 지도 API는 이를 제공하지 않아 실무자가 여러 정부 시스템을
   수작업으로 오간다.

### 1.2 기회
원천 데이터(주소, 좌표, 상가, 지적)는 정부가 공공데이터로 무상 개방 중이다.
부가가치는 정제 품질, 검색 정확도, 배포 형태에서 발생하며, 이는 1인 개발로
구축 가능한 소프트웨어 자산이다. 개발자의 온프레미스 아키텍처 경험(의료 PHI 보호)과
부동산 AI 도메인 지식이 진입 자산이 된다.

### 1.3 핵심 포지셔닝
"카카오보다 싼 API"가 아니라 **"카카오가 팔지 않는 것을 파는 API"**.
저가 경쟁은 카카오의 무료 쿼터 앞에서 성립하지 않는다 (SDP R-07).
차별화 3축: (1) 무제한 벌크 지오코딩, (2) 온프레미스 배포, (3) 부동산 특화 필드.

## 5. 수익 모델

### 5.1 요금 3축 (확정, 2026-07-27)
| 상품 | 형태 | 과금 | 대상 |
|---|---|---|---|
| Bulk | SaaS, 배치 중심 | 건당 30/20/10원(~10만/~100만/100만+건) + 월 최소 30만원. 일일 제한 없음 | 주소 정제 수요 기업, 프롭테크 |
| On-Prem | 설치형 라이선스 | 연 라이선스 3,000만원 + 갱신구독 800만원/년(분기 스냅샷) | 금융/공공/의료 기관 |
| RealEstate | SaaS, parcel 엔드포인트 포함 | 월 구독 Starter 30만 / Pro 100만 / Enterprise 협의 | 감정평가법인, 토지용역, 프롭테크 |

> 근거·경쟁분석·정확도(6-2): `docs/08_Deployment_Pricing_b2d_geo.md` §0/§2-5. 카카오 정상 50원/건 대비 대량서 언더컷, 원가~0(공공데이터), 무료티어 볼륨경쟁은 비목표(§5.3).

### 5.2 원가 구조
- 데이터 원가 0 (공공데이터). 원가는 서버 인프라 + 개발 시간 + ETL 운영 시간.
- 1인 운영 전제이므로 고정비가 낮고, 손익분기 파일럿 1~2건이면 충분하다.

### 5.3 명시적 비목표
- 무료 티어로 볼륨 경쟁하지 않는다. 카카오 무료 쿼터 사용자층은 목표 고객이 아니다.
- 지도 렌더링/길찾기 시장에 진입하지 않는다 (SDP 1.3 범위 외).

## 6. 법적/준법 요구사항

| 항목 | 내용 |
|---|---|
| 데이터 라이선스 | 공공누리 유형별 조건(출처표시 등) 확인 후 이용. 각 데이터셋의 이용약관을 문서로 보관 |
| 금지 사항 | 네이버/카카오/구글 데이터 혼입 금지 (BR-01). OSM은 ODbL share-alike 검토 전 보류 (SDP R-06) |
| 개인정보 | 상가 데이터는 사업장 공개 정보이나, 서비스 로그(usage_log)에 최종 사용자 위치 이력이 축적될 수 있으므로 좌표 로그 보존 기간 정책을 출시 전 수립 |
| 계약 | 파일럿 계약서에 데이터 출처, 정확도 면책(실측 대체 아님), SLA 범위(NFR-05) 명시 |
