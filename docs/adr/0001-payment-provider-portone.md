# ADR 0001: 셀프서브 결제는 포트원 경유 PG로 한다

- 상태: 승인 (2026-08-26)
- 결정자: 조희진

## 배경

Standard 구독(월 9,900원 부가세 포함)의 결제 수단이 필요하다. 초기 계획(tasks/todo.md
Phase 2, deploy/OPS.md 7-1절)은 "토스 정기결제 링크"였다: 대시보드에서 노코드로
정기결제 링크를 만들어 수동 플로우(결제 확인 후 키 발급)로 돌리는 방안.

## 검토한 대안

1. **토스 정기결제 링크 (기각)**: 계획의 전제였던 노코드 정기결제 링크가 실제로는
   제공되지 않았다. 정기결제를 쓰려면 토스페이먼츠 직접 계약이 필요하다.
2. **토스페이먼츠 직접 계약 (기각)**: 초기비용 33만 원. 월 9,900원 상품의 초기
   단계에서 정당화되지 않는다.
3. **MoR(Merchant of Record) 계열 (기각)**: 소액 상품에서 고정비 성격의 수수료
   구조(약 12%)라 단가 대비 과도하다.
4. **포트원(PortOne) 경유 PG 가입 (채택)**: 가입비 0원. 포트원을 통해 PG에
   가입하고 결제 위젯/API를 붙인다.

## 결정

포트원 경유로 PG에 가입한다. PG 심사 요건(이용약관, 개인정보처리방침, 환불정책,
요금표, 사업자정보 게재, 유선전화)을 사이트에 갖추는 것이 Phase 4의 범위이고,
결제 SDK 연동은 심사 통과 후 다음 Phase다.

## 결과

- Phase 4에서 terms/privacy/refund 3종 + 전 페이지 사업자정보 푸터를 게재한다.
- deploy/OPS.md 7-1절의 토스 링크 수동 플로우 문서는 폐기 대상이다. 결제 확인 후
  수동 키 발급이라는 운영 절차 자체는 PG 전환 후에도 심사·연동 완료 전까지 유지한다.
- 심사 접수 전 사용자 작업: 통신판매업 신고({ECOMMERCE_REG_NO} 교체).
